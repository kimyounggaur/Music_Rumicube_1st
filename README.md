# 하모니 빌더 Harmony Builder

음을 모아 코드를 만들고, 완성한 코드가 다음 코드를 쉽게 만드는 2인 로컬 핫시트 음악 교육 보드게임 웹앱입니다. Next.js App Router, TypeScript, Tailwind CSS, Zustand, Framer Motion, Tone.js, Vitest로 구현했습니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검사

```bash
npm test
npm run lint
npm run build
```

## 게임 규칙

- 한 턴에 서로 다른 음계 토큰 3개, 같은 음계 토큰 2개, 카드 빌드, 카드 보관 중 하나를 합니다.
- 같은 음 2개는 시장 풀에 해당 음이 4개 이상 남아 있을 때만 가능합니다.
- 플레이어는 토큰을 최대 10개까지 가질 수 있습니다.
- 완성한 코드 카드의 bonus 음은 이후 카드 비용을 1개씩 줄입니다.
- 황금 쉼표는 부족한 음 하나를 대신 낼 수 있습니다.
- 공개 카드를 보관하면 황금 쉼표를 1개 받습니다. 보관 카드는 최대 3장입니다.
- 특정 bonus 조합을 만족하면 마에스트로 타일을 자동 획득합니다.
- 먼저 15점 이상을 달성하면 승리합니다.

## 수업 활용 예시

- 10분 버전: 튜토리얼을 함께 읽고 Triad 카드만 목표로 플레이합니다.
- 20분 버전: 7th 카드까지 열어 공통음과 할인 엔진을 설명합니다.
- 40분 버전: Progression 카드와 마에스트로 타일까지 플레이하고 게임 로그를 학습 기록으로 돌아봅니다.
